# NichHome Zabbix Console

Mobile-first frontend for an existing Zabbix instance. Zabbix remains the source of truth through the Zabbix API; this app only presents and proxies data.

## Features

- Dockerized Node/Express app with environment-based config
- Server-side Zabbix API login/session reuse
- Current problems via `problem.get`
- Recent events via `event.get`
- Hosts via `host.get`
- Trigger details via `trigger.get`
- Item graph data via `item.get`, `history.get`, and `trend.get`
- Problem acknowledgement via `event.acknowledge`
- Read-only mode to disable acknowledgement
- Optional Grafana panel embeds and dashboard links
- Mobile-first dashboard, problems, hosts, host detail, problem detail, dashboards, and settings views
- No hardcoded private IPs or credentials

## Configuration

Create an `.env` file or set variables in your container platform:

```env
APP_PORT=3000
ZABBIX_API_URL=https://zabbix.example.com/api_jsonrpc.php
ZABBIX_USERNAME=api-user
ZABBIX_PASSWORD=change-me
GRAFANA_ENABLED=false
GRAFANA_URL=
GRAFANA_API_KEY=
READ_ONLY=false
SESSION_TTL_SECONDS=900
REQUEST_TIMEOUT_MS=12000
```

Secrets are only read by the backend. They are never returned to frontend JavaScript.

## Run With Docker Compose

```bash
docker compose up --build
```

Open `http://localhost:3000`, or the port you set with `APP_PORT`.

## TrueNAS SCALE Install

Use the published container image instead of cloning the repo inside TrueNAS.

In TrueNAS SCALE, go to **Apps**, then **Discover Apps**, then use **Custom App** or **Install via YAML**. Paste this compose file and replace the Zabbix values:

```yaml
services:
  nichhome-zabbix-console:
    image: ghcr.io/jcnicholls123/nichhome-zabbix-console:latest
    container_name: nichhome-zabbix-console
    ports:
      - "3000:3000"
    environment:
      APP_PORT: 3000
      ZABBIX_API_URL: "http://YOUR-ZABBIX-SERVER/api_jsonrpc.php"
      ZABBIX_USERNAME: "YOUR-ZABBIX-API-USER"
      ZABBIX_PASSWORD: "YOUR-ZABBIX-PASSWORD"
      GRAFANA_ENABLED: "false"
      GRAFANA_URL: ""
      GRAFANA_API_KEY: ""
      READ_ONLY: "false"
      SESSION_TTL_SECONDS: 900
      REQUEST_TIMEOUT_MS: 12000
    restart: unless-stopped
```

Then open:

```text
http://YOUR-TRUENAS-IP:3000
```

If TrueNAS cannot pull the image, check that the package is public at:

```text
https://github.com/jcnicholls123/nichhome-zabbix-console/pkgs/container/nichhome-zabbix-console
```

## Grafana

Grafana is optional. Set `GRAFANA_ENABLED=true` and `GRAFANA_URL` to enable dashboard links and panel embeds. `GRAFANA_API_KEY` is only used by backend proxy routes and is not exposed to the browser.

Dashboard UID and panel IDs are configured in the app Settings screen. Variables supported in generated Grafana URLs:

- `var-host`
- `var-item`
- `var-interface`
- time range `from` and `to`

When Grafana is disabled or unmapped, the UI falls back to Zabbix history graph areas.

## Security Notes

- Zabbix and Grafana requests are proxied or generated by the backend.
- Passwords and API keys are never serialized to `/api/config`.
- API output is sanitized to strip common secret-shaped fields.
- `READ_ONLY=true` disables acknowledgement actions.
- The app uses Helmet, JSON body limits, and rate limiting.
